# Service Desk Simulator | ООО «Про.Софт»

Обучающий веб-симулятор для инженеров технической поддержки. Проект симулирует работу Service Desk и помогает отработать навыки регистрации обращений, распределения задач и решения инцидентов (включая управление проблемами по методологии ITIL).

## 🎮 Режимы игры (Уровни)

Симулятор состоит из трех независимых уровней. Вы можете проходить их в любом порядке, прогресс сохраняется автоматически.

Уровень 1 — Регистрация обращений: Разбор входящих, заполнение карточки, определение типа обращения, категории, важности и срочности по матрице приоритетов.

Уровень 2 — Распределение (Тимлид): Назначение ответственных с учетом их загруженности и специализации, эскалация менеджеру.

Уровень 3 — Решение инцидентов (Инженер 2 линии): Проведение диагностики (логи, конфигурация, лицензии), поиск первопричины, выбор обходного и радикального решений, а также управление проблемами (Problem Management) и Known Error.

## ✨ Особенности

- **Data-Driven архитектура:** Задачи, справочники и схемы форм описаны в JSON.
- **Dynamic Anchors (D.5):** Поля форм генерируются на лету с уникальными ID, доступ к ним идет через `Registry` (`state.currentForm`), а не через `getElementById`.
- **Schema-Driven UI (Roadmap E):** UI-обвязка карточки (панели, кнопки) определяется ключом `template` в JSON-схеме. Больше не нужно дублировать `screen-work` для разных уровней.
- **Сохранение прогресса:** Данные сохраняются в `localStorage` браузера.
- **База знаний:** Встроенный справочник по ITIL, SLA, типам обращений и методам расследования.
- **Автотесты:** Встроенная система проверки знаний (включая негативные тесты).

## 🚀 Быстрый старт

Вы можете запустить проект двумя способами:

### Вариант 1: Локальный сервер (Рекомендуемый)
Так как проект использует JSON-файлы и ES-модули, лучше запускать его через локальный сервер:
```bash

Если установлен Python:
python -m http.server 8000

Или через Node.js:
npx serve .
```
Откройте `http://localhost:8000` в браузере.

### Вариант 2: Прямой запуск (file://)
Проект поддерживает запуск по двойному клику на `index.html`. Однако для этого сначала нужно собрать данные:

Установите зависимости: `npm install`

Соберите бандл данных: `npm run build`

Откройте `index.html` в браузере.

## 🛠️ Для разработчиков и контент-менеджеров

### Структура проекта
```text
├── data/
│ ├── common/         # Справочники (орг., сотрудники, матрица)
│ ├── levels/         # Манифесты уровней (очередь, интро, схема)
│ ├── schemas/        # Схемы карточек (поля + ключ template для UI)
│ └── tickets/        # Задачи по уровням
│  
├── js/
│ ├── core/           
│ │ ├── state.js      # Состояние (включая currentForm Registry)
│ │ ├── dataStore.js  # Единая точка доступа к данным
│ │ ├── formRenderer.js# Генератор полей по JSON-схемам
│ │ ├── templateRenderer.js # (Roadmap E) Генератор UI-обвязки
│ │ ├── validator.js  # Валидатор ответов
│ │ └── progressStore.js
│ ├── app.js          # Точка входа, роутинг (становится тоньше)
│ └── autotests.js    # Встроенные автотесты
...

### Как добавить новую задачу?

Откройте нужный файл (например, `data/tickets/l1.json`).

Добавьте новый объект задачи (скопируйте существующий и измените `id`, `title`, `text`, `etalon`).

В терминале выполните: `npm run build`.

Обновите страницу в браузере. Новая задача появится в очереди!

### Как изменить поля карточки или её внешний вид?
1. Для изменения полей — редактируйте массив fields в data/schemas/card-lX.json.

2. Для изменения внешнего вида (лейаута, панелей) — измените ключ "template" в схеме или отредактируйте соответствующий шаблон в js/core/templateRenderer.js.
